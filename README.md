# Note-Grab
Want to grab notes while on the internet no problem, check out this note-grabber that works online.

## Project Objective
This project serves to display a simple program using HTML, CSS, JavaScript & Microsoft SQL to create a note grabber that works online and takes notes. This will save notes into a basic SQL databse which can be retreieved, displayed and edited by the user. It will work based on a singular user in this current iteration (Not for more than one user).

## Code Stack
  - HTML
  - CSS
  - JavaScript
      - Framework to be verified
  - SQL
      - Microsoft SQL Server

# Project Description
This applictaion has two parts the User Interface and the functionality.
  - User Interface: The interface will be a webpage(s) that the user will interact with, which will send HTTP Request methods that will update, add new and display the notes the user has created. This will be done mostly by HTML, CSS, JavaScript languages
  - Functionality: The functionality will be taking in notes, displaying them and updating in the users request also through HTTP Request methods, this will be done using mainly JavaScript and SQL.

This project has to environment, dev(development) and production, dev serves a means for development & testing grounds, and production serves an environment to hold running & executable code that has the fully functioning app.
